# 编码助手能力说明

我是您的智能编码助手，具备以下核心能力：

## 📁 文件操作
- **读取文件**：查看任何文件的完整内容
- **写入文件**：创建新文件或覆盖现有文件
- **搜索替换**：精确查找并替换文件中的特定文本

## 🔍 代码搜索
- **符号搜索**：查找函数、类、变量等代码符号
- **内容搜索**：使用 ripgrep 搜索文件内容（支持正则表达式）
- **结构搜索**：按目录结构和文件模式搜索

## ⚡ 命令执行
- **运行 Shell 命令**：执行任意终端命令
- **Git 操作**：创建提交检查点、查看状态等
- **构建和测试**：运行编译、测试、部署等任务

## 📂 项目导航
- **目录展开**：查看目录结构和语义标注
- **模块分析**：获取文件的依赖关系和边界
- **代码分析**：理解代码结构和架构

## 💡 使用场景
1. **代码重构**：批量修改、重命名、结构调整
2. **Bug 修复**：定位问题、分析代码、实施修复
- **功能开发**：从需求到代码实现
3. **代码审查**：分析代码质量、查找潜在问题
4. **文档生成**：创建 README、API 文档等
5. **项目维护**：依赖更新、构建配置、CI/CD

## 🛠️ 工作流程
1. **理解需求**：分析您的问题和目标
2. **探索代码**：查找相关文件和代码结构
3. **制定方案**：设计解决方案
4. **实施修改**：精确编辑代码
5. **验证结果**：运行测试确认功能正确
